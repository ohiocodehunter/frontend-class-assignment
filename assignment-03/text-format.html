Assignment 3 • Task 3: Text Formatting

Aim: Format inline text using semantic tags: strong importance, emphasized stress, and line breaks.

File: text-format.html
Tags Used: <strong>, <em>, <br>

Text Formatting Demonstration

Rendered Output

Writing standard compliant markup is the bedrock of modern frontend engineering.
Dividing text across deliberate line breaks allows for distinct readability without creating an entirely new paragraph container.

It is essential to use semantic tags for accessibility because screen readers convey tone and urgency to users, ensuring the content is truly meaningful.

Semantic Distinction:
  • <strong> conveys serious importance or urgency (not merely visual boldness).
  • <em> alters sentence stress and pronunciation emphasis.
  • <br> produces a line break within text (e.g. poems, addresses, or stanza lines).
