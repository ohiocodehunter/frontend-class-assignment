Assignment 12 • Task 1: Box Sizing Comparison

Aim: Compare how content-box adds padding and border to the specified width, while border-box absorbs them inside the specified width.

File: box-model.html
Dimensions: width: 200px; padding: 20px; border: 5px solid;
Modes: content-box vs border-box

Visual Dimension Comparison

Rendered Output

1. content-box (Standard Box Sizing)

box-sizing: content-box
Rendered Width: 250px
[200px + 40px padding + 10px border]

2. border-box (Modern Predictable Sizing)

box-sizing: border-box
Rendered Width: exactly 200px
[Content shrinks to 150px to accommodate padding & border]
Industry Standard Practice: Modern web resets universally apply * { box-sizing: border-box; } so that adding padding or borders never unexpectedly breaks grid columns or causes container overflow.
