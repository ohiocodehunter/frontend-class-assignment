## 📑 Lab Assignments Index

This repository contains all 15 laboratory assignments for the **HTML & CSS Development Lab (BCS554)**, organized strictly according to the syllabus requirements with individual folders, source files, and sample outputs.

| # | Assignment Title | Aim | Submitted Files |
|---|---|---|---|
| **01** | [Starting a Git Repository](assignment-01/) | Start a Git repository, configure local identity, and save commits. | `html-lab/index.html`, `terminal-output.txt` |

| **03** | [Your First HTML Page](assignment-03/) | HTML document structure, heading hierarchy, and inline formatting. | `first.html`, `headings.html`, `text-format.html` |
| **04** | [Divs, Attributes and a Small Fix](assignment-04/) | Layout grouping with divs, data-* attributes, and fixing syntax errors. | `layout.html`, `attributes.html`, `attendance-fixed.html` |
| **05** | [Links and Images](assignment-05/) | Hyperlinking pages and rendering accessible images with alt tags. | `home.html`, `portfolio.html`, `portfolio-image.html` |
| **06** | [Types of HTML Lists](assignment-06/) | Unordered bullet lists, nested ordered lists, and definition lists. | `shopping-list.html`, `canteen-menu.html`, `faq.html` |
| **07** | [About Me Page](assignment-07/) | Semantic HTML5 structure (header, nav, main, section, footer with mailto). | `about-me.html` |
| **08** | [Sign-Up Forms and Choices](assignment-08/) | Forms with text, email, password, radio buttons, select dropdowns, and validation. | `signup.html`, `choices.html`, `signup-required.html` |
| **09** | [Tables with Headers and Footers](assignment-09/) | Tables with thead, tbody, tfoot, captions, and accessibility scopes. | `marks.html`, `marks-average.html`, `marks-accessible.html` |
| **10** | [CSS Fundamentals](assignment-10/) | Applying CSS via inline, internal, and external linked stylesheets. | `inline-internal.html`, `style.css`, `linked.html` |
| **11** | [Units and CSS Variables](assignment-11/) | Absolute (px) vs relative (%, rem) units and :root CSS variables / design tokens. | `units.html`, `variables.html`, `tokens.css`, `tokens.html` |
| **12** | [Box Model, Cards and Scrolling](assignment-12/) | content-box vs border-box, rounded card components, and overflow scrolling. | `box-model.html`, `card.html`, `scroll.html` |
| **13** | [Flexbox Layouts](assignment-13/) | Horizontal flex navbar, centered pricing cards, and wrapping shop grid. | `nav-flex.html`, `centred-cards.html`, `wrapping-cards.html` |
| **14** | [CSS Grid Layouts](assignment-14/) | Fractional units grid, auto-fill minmax photo gallery, and dashboard areas. | `grid-first.html`, `gallery.html`, `dashboard-areas.html` |
