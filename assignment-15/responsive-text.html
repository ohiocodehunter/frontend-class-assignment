Assignment 15 • Task 3: Responsive REM Typography

Aim: Set a base font size of 1rem for body text and 1.5rem for h1, expanding h1 to 2.5rem at the 600px breakpoint.

File: responsive-text.html
Base Body: 1rem
Base H1: 1.5rem
Breakpoint (≥600px): h1 { font-size: 2.5rem; }

Fluid Typography Demonstration

Live Scaling Test

Adaptive Typography with REM Breakpoints

On mobile displays under 600px, this heading renders at a compact 1.5rem (24px) to avoid awkward text hyphenation and screen crowding. Once the viewport reaches 600px or wider, the media query smoothly expands the heading to an impactful 2.5rem (40px).
