Responsive Media Queries

Assignment 15 • Task 1: Mobile-First Card Layout

Aim: Write mobile-first default styles where cards stack on phone screens, and apply a min-width: 600px media query to place them side by side.

File: mobile-first.html
Meta Tag: viewport
Breakpoint: @media (min-width: 600px)

Mobile-First Responsive Testing

Breakpoint: 600px

Mobile Strategy

The mobile-first paradigm establishes lightweight base styles prioritizing cellular networks and compact touch displays before progressively enhancing with complex multi-column arrangements.

Desktop Expansion

When the viewport achieves 600px or wider, the media query smoothly switches flex-direction: column to row, dividing the available screen width equally across both cards.

Try It Live: Resize your browser window below and above 600px width. You will see the two cards toggle between a vertical column stack on narrow screens and an elegant horizontal row on wide screens.
