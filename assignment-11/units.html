CSS Measurement Units

Assignment 11 • Task 1: Absolute & Relative Units

Aim: Compare absolute pixel dimensions (px) with relative percentage (%) container scaling and root relative font sizing (rem).

File: units.html
Box 1: width: 200px; height: 40px;
Box 2: width: 50%; height: 40px;
Text: font-size: 1.5rem;

Rendered Units Comparison

Rendered Output
200px × 40px (Fixed)
50% Width × 40px (Fluid)

This paragraph text is rendered at exactly 1.5rem (24px based on a 16px root font size).

Why rem is Superior for Typography: Unlike px, which ignores user operating system accessibility settings, rem scales proportionally with the user's browser-level font size preferences, ensuring inclusive accessibility.
