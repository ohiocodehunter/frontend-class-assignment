Assignment 11 • Task 2: CSS Variables in :root

Aim: Define reusable design variables in the :root pseudo-class and apply them via var() functions.

File: variables.html
--main-color: #1d3557
--accent-color: #e63946
--page-padding: 20px

Custom Properties Rendering

Rendered Output

Design System Headings with Accent Color

This paragraph is rendered using var(--main-color) which resolves to deep navy (#1d3557). The heading above utilizes var(--accent-color) which resolves to vibrant crimson (#e63946). The container padding is controlled globally by var(--page-padding) set to 20px.

Why CSS Variables are Dynamic: Unlike preprocessor variables (Sass/Less) which compile to static values, CSS Custom Properties stay live in the browser DOM. They can be dynamically updated at runtime using JavaScript or overridden within media queries.
